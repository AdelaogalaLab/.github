# Adelaiye-Ogala Lab

The Adelaiye-Ogala Laboratory is a basic science and translational research lab in the Division of Hematology/Oncology, Department of Medicine, at the Jacobs School of Medicine and Biomedical Sciences, University at Buffalo.

Our laboratory is dedicated to investigating genitourinary cancers and developing novel therapeutic strategies for lasting clinical outcomes. We also provide a platform for nurturing the next generation of cancer researchers and leaders in STEM.

This GitHub profile hosts code and computational analyses associated with publications from our laboratory. Each publication entry links to the repository containing the supporting computational analysis and documentation.

For more information about our research, publications, and laboratory, visit the [Adelaiye-Ogala Laboratory website](https://adelaiye-ogala-laboratory.com/).

We encourage other researchers to use these resources in their work. Please cite the associated publication when using code, data, or analysis resources from a project repository, and follow any data access or use requirements described for that study.

## GitHub-hosted reproducible analysis

### [MECOM Function Is Critical for AR-Driven Treatment-Resistant Prostate Cancer](https://doi.org/10.1158/0008-5472.CAN-25-1720)

This repository contains the computational code and configuration used for the RNA-seq analyses reported in the associated *Cancer Research* article, including quality control, expression analysis, differential expression, gene set enrichment, pathway analysis, survival analysis, and generation of manuscript-associated analysis outputs.

RNA-seq and ChIP-seq data, together with associated metadata, are available through GEO under accession **GSE292273**.

[GitHub repository](https://github.com/AdelaogalaLab/Bulk_rnaSeq)
